METHOD DISCUSSION / 2026.10

如何用机器学习势，
更可靠地优化 LRM / 非晶 Li₃PO₄ 界面？

本页讨论一条具体路线：机器学习势负责探索和优化几何，DFT负责校验结构并计算电荷密度、DOS/PDOS与结合能。重点是解释主动学习如何嵌入当前“只有一个界面起始结构”的工作流。

讨论边界

当前只有一个 288 原子界面起点。优化轨迹可以提供局部构型，但不能代表多个独立非晶界面或全局最低能结构。

01 / STARTING POINT

从实验问题到计算瓶颈

逻辑起点不是“ML势能不能跑”，而是当前结构优化既耗费DFT成本，又需要判断势模型能否描述真实的界面局部环境。

实验

包覆样品表现改善

倍率性能提高、GITT表观 Li⁺ 扩散系数提高、阻抗降低。需要解释这些现象是否与局部界面结构和电子态变化相容。

现有计算

结构与电子结果需要分开验收

两层 288 原子模型仍在结构优化中；ML预优化可帮助探索，但其几何必须通过目标DFT受力检查。

方法问题

怎样把DFT用在最有信息量的地方？

不是放弃DFT，而是让ML势承担高频几何搜索，将少量DFT计算用于校正和验收，再用DFT得到最终电子性质。

02 / WHAT WE KNOW

当前进展：有预优化尝试，尚未形成主动学习闭环

以下数值来自 2026.10.27 的本地项目记录。它们说明为什么需要DFT验收，不代表已经证明DPA4可靠或不可靠。

0.401 eV/Å

程序结束不等于结构达到受力收敛。

0.642 Å

DPA4几何上的DFT单点

因此尚无可用的该几何DFT力标签；这次失败不能单独归因于ML势。

03 / ML INTERATOMIC POTENTIAL

机器学习势学的是原子受力与能量，不是电子结构

训练数据通常由DFT对不同原子构型计算得到。ML势拟合能量—几何关系，随后可快速估算新构型的能量和力，用于结构优化或分子动力学。

ML势直接给出近似能量、原子受力；部分模型还给应力或辅助磁矩信息。
ML势不自动给出DFT自洽电子密度、差分电荷、可靠DOS/PDOS或界面电势。
核心风险ML极小值满足 ∇EML ≈ 0，不保证DFT力 ∇EDFT 也小，尤其是训练数据少见的表面、缺陷和界面环境。

04 / TWO ROUTES

预优化路线与主动学习路线的关系

主动学习不是另一种电子结构方法，而是改进ML势训练数据、让它在目标界面附近更可信的一种迭代方式。

路线实际步骤适用判断
ML预优化 → DFT最终优化 → 电子结构ML找到合理起点，DFT继续优化几何，再在验收结构上做电子性质。可靠性较直接，DFT离子步较多；适合作为少量代表结构的对照。
ML优化 → DFT力验收 → 电子结构DFT在固定ML几何上自洽并计算力；通过标准后不更新原子，直接计算性质。可省完整DFT几何优化，但最终是否可省由目标DFT受力和性质敏感性决定。
主动学习 + ML优化 → DFT验收在ML探索中挑选不确定/新颖构型做DFT标注，更新模型后继续优化与筛选。当界面搜索、非晶样本或迁移路径较多时更有价值；不会消除DFT标注成本。

05 / ACTIVE LEARNING LOOP

主动学习：让DFT优先检查模型最可能出错的构型

模型探索结构空间，DFT提供可信标签，模型再从新增样本中学习。每一轮都必须保留数据来源、收敛状态与模型版本。

01 · 起始模型

已有DFT数据 + 初始势

覆盖目标元素、体相、表面、非晶局部和界面接触环境。

02 · 探索

ML优化与采样

输出结构轨迹；探索不同接触距离、局部配位和小扰动。

03 · 查询

选择有信息量的样本

模型分歧、新局部配位、力突变、异常位移或外推信号。

04 · 标注

对选中构型做DFT

自洽收敛后保存能量和力；不收敛结果先诊断，不当标签。

05 · 更新

微调/重训并再验证

重启探索；用独立构型检查力误差和最终DFT残余力。

关键区别：主动学习不是把每一步优化轨迹都送去DFT，而是避免重复标注相似帧，优先计算模型不熟悉、且会影响结构判断的构型。它减少冗余DFT调用，不会免除DFT。

06 / ONE STARTING STRUCTURE

只有一个起始结构，如何做主动采样？

一条优化轨迹会产生多个几何构型，可支持当前局部能量盆地的自适应采样；但这些相关帧不等于独立非晶样本。

  1. 分段运行并保存轨迹

    保留坐标、能量、原子力和每步是否收敛；不要只留下最终结构。

  2. 按物理变化选帧

    优先选配位变化、新的跨界面接触、较大位移、异常受力或不同候选模型分歧大的几何。

  3. 去除冗余，保留代表性

    相邻优化步通常高度相关。按局部环境/结构差异挑少量帧，另留出独立帧做盲测。

  4. DFT标注并更新势

    用与最终性质分析一致的方法得到收敛的能量和力，再决定是否微调DPA4或另训适配势。

  5. 重复到通过验收

    更新后继续ML优化，最终用DFT检查目标结构受力、局部配位及关键性质的几何敏感性。

当前必须核实的两个能力

不确定度：当前DPA4接口是否提供可靠的外推/不确定度指标？若没有，可用多个模型委员会；若也没有，按配位变化等事件选帧，这应称作较弱的DFT在环自适应采样。

模型更新：当前DPA4-Neo版本是否支持用本项目DFT数据微调？若不支持，不能假设它会在计算过程中自动学习；需建立兼容的微调或局部训练流程。

在这两项查明前，能确定的是“可以沿轨迹选构型做DFT验证”，还不能声称已搭建完整主动学习系统。

07 / ACCEPTANCE GATES

什么证据足以让ML结构进入电子性质分析？

训练集平均误差和ML优化器收敛都只是模型指标。结构是否可用于本项目，最终要回到目标DFT方法和具体界面。

GATE 01

DFT电子自洽

使用与后续性质一致的PBE+U、磁性和色散设置；电子不收敛时，能量与力不能作为验收结果。

GATE 02

DFT残余力

在同一固定几何上评估力。项目现用最大受力分量 ≤ 0.05 eV/Å；这是项目标准，不是普适文献门槛。

GATE 03

界面局部结构

检查PO₄、TM—O/Li—O配位、周期边界、固定层反力和异常接触；不能只看总体平均误差。

GATE 04

性质敏感性

对代表结构比较电荷转移方向、PDOS关键能窗、结合能排序；若短程DFT细化显著改变结论，就不能省略细化。

受力口径：最大力分量 max|Fiα| 与最大原子力模 max|Fi| 不相同；报告时需写清使用哪个量，并只对可动自由度应用几何收敛阈值。固定层反力仍应检查。

08 / DISCUSSION DECISION

当前项目的建议决策

针对“只有一个界面起点”，先建立最小可验证闭环，再决定是否投入更完整的主动学习训练。

先做：最小验证路线

保留DPA4轨迹 → 选取发生明显配位/位移变化的少数代表帧 → 先解决这些几何上的DFT自洽 → 检查能量和受力 → 必要时做兼容的微调或短程DFT细化。通过后再重算差分电荷、DOS/PDOS和结合能。

暂不声称：完整主动学习已完成

目前只有一个结构来源；DPA4单点DFT尚未收敛；模型不确定度与微调能力还需确认。现有信息不足以说已获得ML势优化成功结构，或该结构已可直接代表稳定界面。

建议与老师确认：本阶段是否先以DPA4作为低成本几何提案器、DFT单点力作为验收；是否允许对少数代表结构短程DFT细化作对照；后续是否扩展到独立非晶样本、界面间距/配准和Li迁移路径。
