0.2冻结 DFT 设置并抽查收敛性

阶段 3 的判据（max|F| ≤ 0.05 eV/Å）只在"DFT 本身已收敛"的前提下成立。 否则无法区分偏差来自 ML 模型还是数值设置，而 B1/B2/B3 的分支完全依赖这个区分。 因此收敛抽查必须前置，而不是等到诊断阶段。

动作

  1. 从生产任务复制 INPUT / KPT 原文，逐行核对基线表，写入 dft_settings_frozen.json（含各文件 sha256）。
  2. 此后全部 DFT 任务（单点、离子步、性质）从该 JSON 渲染，禁止手改。

0.3力基势能面标定

要回答的问题是：在 PBE+U+D3(BJ) 这个势能面上，模型的力误差有多大、偏差集中在哪里。 方法只用两种无偏移量：力（可直接比较），以及能量差（作差后偏移消失）。

方法

  1. 力：同一批帧比较 ML 力与 DFT 力的 MAE / RMSE，并按元素与区域（界面 / LRM 体相 / LPO 体相）分组。
  2. 相对能曲线：用层间距变体（gap3.5/4.0/4.5/5.0 Å 或 gap15 阶梯），以最低能帧为参考，比较 ΔEML(d) 与 ΔEDFT(d) 的斜率与曲率。
  3. 色散的角色：D3(BJ) 已在基线内。要验证的是模型是否重现了 D3 带来的层间距能量曲率，由步骤 2 直接给出。
# calib_pes.py —— 只使用力与相对能，不使用绝对总能 import numpy as np, dpdata from deepmd.infer import DeepPot MODELS = {"max": "DPA4-Max-OMat24-v20260911.pt", "neo": "DPA4-Neo-OMat24-v20260805.pt"} # ⚠ dpdata 的 atom_types 是「该数据集自己的 type_map」索引；DPA4-Max 用全元素表。 # 直接 pot.eval(coords, cell, dft["atom_types"]) 会把 Li 当成 Be → 静默算错。 # 必须先重映射：tm = pot.type_map; atype = [tm.index(ELE6[t]) for t in dft["atom_types"]] dft = dpdata.LabeledSystem("labels_dft", fmt="deepmd/npy") coords = dft["coords"]; cells = dft["cells"]; types = dft["atom_types"] F_dft = dft["forces"] # (nframes, natoms, 3) E_dft = dft["energies"] # 仅用于相对能 region = np.load("region_mask.npy") # 0 界面 / 1 LRM / 2 LPO natoms = dft.get_natoms() report = {} for name, path in MODELS.items(): pot = DeepPot(path) F_ml, E_ml = [], [] for i in range(len(coords)): e, f, _ = pot.eval(coords[i], cells[i].reshape(3, 3), types, atomic=False) E_ml.append(float(e[0])); F_ml.append(f[0]) F_ml = np.array(F_ml); E_ml = np.array(E_ml) dF = F_ml - F_dft entry = {"f_mae_all": float(np.abs(dF).mean()), "f_rmse_all": float(np.sqrt((dF ** 2).mean()))} for r, tag in [(0, "interface"), (1, "lrm"), (2, "lpo")]: m = (region == r) entry[f"f_mae_{tag}"] = float(np.abs(dF[:, m]).mean()) # 相对能：各自以最低能帧为参考，偏移自动消掉 dE_ml, dE_dft = E_ml - E_ml.min(), E_dft - E_dft.min() entry["dE_slope"] = float(np.polyfit(dE_dft, dE_ml, 1)[0]) # 目标 ≈ 1 entry["dE_rmsd_meV_per_atom"] = float( np.sqrt(((dE_ml - dE_dft) ** 2).mean()) / natoms * 1000) report[name] = entry print(report) # 写入 calib_report.json，作为判断 B 的输入

判据（本步骤只产出数字，不做设置决策）

量含义参考门槛
f_mae_all整体力 MAE≤ 0.03 eV/Å → 可直接进阶段 1
f_mae_interface界面区力 MAE显著高于体相 → 微调应聚焦界面帧
f_mae_TMMn / Co / Ni 上的力 MAE偏大 → 指向 PBE 与 PBE+U 势能面混合问题
dE_slope相对能斜率≈ 1 且 dE_rmsd 小 → 能量面一致
dE_rmsd相对能 RMSD曲率不符 → 长程/色散处理不一致
成本提示：若没有同一 INPUT 下的多帧 DFT 标签，本步骤需要 3-5 个单点。优先复用历史任务；能复用就不新算。

0.4结构完整性闸门

结构审查报告.md 已记录一个需要正视的事实：LPO 侧来自 packmol + 高温退火的非晶 slab， 12 个 P 中有 7 个配位数仅为 3，只有 5 个保持完整 PO₄，界面附近存在被截断的四面体。 这决定了初始力有多大，也决定了 ML 弛豫会不会给出"看起来合理但物理上无意义"的重构。

检查项（零 DFT 成本，全部脚本化）

  • P 配位数分布：4 配位 / 3 配位 / 其他各多少个，是否集中在界面；
  • 最短接触：是否存在 < 0.8 ×（共价半径和）的原子对；
  • 层间距：界面最小间距是否 > 2.0 Å；
  • 化学计量与价态簿记：Li / Mn / Co / Ni 名义价态之和是否与体系电荷一致。
这一步的产出是一个待决策问题，不是一个自动通过的检查。 需要老师在两个选项间定夺：接受现状、依赖弛豫修复；或先修结构（补氧 / 退火 / 换用晶体 Li₃PO₄）再投入 ML + DFT。 建议把两个选项连同代价一起提交，不在文档里默认其一。

1.1弛豫脚本

结构读写必须经 abacustest 或 dpdata：ASE 没有 ABACUS STRU 的读写器，STRU 也不是 QE 输入格式。

# relax_dpa4.py import numpy as np from ase.optimize import LBFGS from ase.constraints import FixAtoms from abacustest.lib_prepare.stru import AbacusSTRU from deepmd.calculator import DP # DeePMD-kit 3.x；旧版本为 deepmd.ase.DP stru = AbacusSTRU.read("structure_original.stru", fmt="stru") atoms = stru.to("ase") # 固定原子索引来自结构文件本身，不用"240-287"这类口头约定 fixed = np.loadtxt("fixed_atoms.txt", dtype=int) atoms.set_constraint(FixAtoms(indices=fixed.tolist())) atoms.calc = DP(model="DPA4-Max-OMat24-v20260911.pt") # 单任务 Default，无需指定 head opt = LBFGS(atoms, trajectory="relaxed.traj", logfile="opt.log") opt.attach(lambda: print(f"{opt.nsteps:4d} E={atoms.get_potential_energy():.6f}"), interval=10) opt.run(fmax=0.02, steps=1000) out = AbacusSTRU.from_ase(atoms) out.write("optimized_final.stru", fmt="stru", direct=True) atoms.write("relaxed.extxyz") # 便于后续对照与标定复用

参数约定

  • maxstep 0.1 Å：当前实测可用的步长。
  • fmax 0.02 是 ML 力收敛限，与 DFT 验收判据（0.05 eV/Å）是两回事，不得混用。
  • 固定原子清单必须与 STRU 内 m 0 0 0 标记一致，不一致会静默改变体系。

1.2轨迹审计与跨模型对照

审计项（每 10-20 帧检查一次）

  • 能量趋势：单调下降或平台收敛，出现突增即停；
  • 单步最大位移：> 0.1 Å/步即停；
  • PO₄ 完整性：P–O 键 1.5-1.7 Å；界面最小间距 > 2.0 Å；
  • 模型偏差：沿轨迹用双模型 committee 计算，若单调增长说明已进入模型不可信区，立即停止。
# 跨模型偏差：既用于轨迹审计，也用于终点可信度判定 # 参数名以本机 `dp model-devi -h` 为准 dp model-devi -m DPA4-Max-OMat24-v20260911.pt \ DPA4-Neo-OMat24-v20260805.pt \ -s traj_sys -n 200 -o devi.out

起点策略

  • 层间距阶梯：间距 0.2-0.4 Å 步长扫描（已有 gap15 变体）；
  • 跨模型对照：同一起点分别用 Max / Neo 独立弛豫。

随机微扰（±0.05 Å）基本仍在同一势阱内，信息量低，不作为起点策略。

已有实测结果（作为基线）：Air 终点相对起点平均位移 0.702 Å、127 个原子 > 0.5 Å（占 288 原子的 44%）； Neo 0.535 Å / 106 个原子。两个独立模型差到这个程度，本身就是阶段 2 判断 A 的核心输入。 口径：全部 288 原子、相对同一起点，见 MLIP零成本预检报告_20261102.html。

3.2成本模型

实测事实：单步 SCF 迭代数呈双峰——收敛步约 40 次，落入慢/振荡区 180+ 次，scf_nmax 600。

# 每个量都用本项目实测值代入 cost(离子步 i) = iter_i × c_iter cost(一次 DFT 验收) = Σ_i cost(i) + c_init iter_i ∈ {~40, ~180+} # 双峰；任务执行时记录真实分布 c_iter = 单次 SCF 迭代墙钟（由已完成任务反算） c_init = 首次 SCF / 随机初始化开销 # 历史锚点：50 个离子步后 max|F| = 0.401 eV/Å，距 0.05 仍很远
结论：在 288 原子 / lcao / 100 Ry / scf_thr 1e-6 的配置下，把纯 DFT 弛豫跑到 0.05 eV/Å 的期望离子步数在 10² 量级，每步又要 40-180+ 次 SCF 迭代。 这既是"必须先用 ML 推到近邻"的依据，也意味着任何按"单点数"做的预算都会低估 1-2 个数量级。

3.3验收判据与提取

判据（必须全部满足）

  • SCF 收敛达标（scf_thr 1e-6，scf_thr_type 2），能量与磁矩历史无跳变；
  • 可动原子 max|F| ≤ 0.05 eV/Å（力的模；固定原子不参与）；
  • 可动原子 RMS(F) ≤ 0.03 eV/Å，防止"单点尖峰达标、整体仍不收敛"；
  • 无异常短接触（> 0.8 × 共价半径和）；PO₄ 完整（P–O < 1.7 Å）；
  • TM 局域磁矩相对起点未退磁、未跳变（任一 TM 变化 > 0.5 μB 视为磁态改变）。
# check_accept.py import numpy as np, dpdata ds = dpdata.LabeledSystem("OUT.ABACUS", fmt="abacus/md") # 或 abacus/relax F = ds["forces"][-1] # 最后一帧 (natoms, 3) natoms = ds.get_natoms() fixed = np.loadtxt("fixed_atoms.txt", dtype=int) mov = np.setdiff1d(np.arange(natoms), fixed) fmag = np.linalg.norm(F[mov], axis=1) fmax = float(fmag.max()) frms = float(np.sqrt((F[mov] ** 2).sum(axis=1).mean())) verdict = "PASS" if (fmax <= 0.05 and frms <= 0.03) else "FAIL" print(f"max|F|={fmax:.4f} RMS={frms:.4f} movable={mov.size} {verdict}")
若只做 1 个离子步：判据照上式算，同时记录残力下降斜率，作为"DFT 侧是否也朝同一极小值走"的证据。单步不下降，说明该 ML 终点在 DFT 面上不是下降方向。
3.4同起点对照（最锋利的单个判据）

从同一个初始磁态出发做 DFT+U 弛豫：若 DFT+U 只移动 < 0.3 Å，而 MLIP 移动了 ~2.85 Å，则该次 ML 弛豫是假象。 反之若两者位移量级一致，说明模型至少在方向与步长上可信。已有的 Air（0.702 Å 均值 / 127 个原子）与 Neo（0.535 / 106）位移统计可直接作为对照分母。

阶段 4

标签生成与 LoRA 微调

2-4 周 · 标签 10² 量级
4.1标签生成的三条铁律
  1. 只沿 DFT+U 路径生成：帧来自 DFT 自己的离子步轨迹，不来自 MLIP 的假象路径，否则等于把错误势能面固化进模型。
  2. 一个数据集只对应一个势能面：不混入无 U、不同 U 或不同泛函的帧。
  3. 覆盖实际使用条件：目标是让模型在它将被使用的构型上准确，而不是在模型开发者预设的构型上准确。

复验与稳定性

阶段 5 必做 · 阶段 6 按需

阶段 5：用微调后的模型重跑阶段 1 → 2 → 3 全链，且必须使用与旧模型完全相同的初始结构与 INPUT，否则无法归因。 只有全套判据通过，才允许进入阶段 7。

阶段 7

性质计算

3-5 天 · DFT 单点 5-10 个 · 仅验收通过后

对验收通过的结构计算：界面 SCF（阈值可收紧到 1e-7）、差分电荷密度（界面 − LRM 片段 − LPO 片段）、平面平均电荷、DOS / PDOS、结合能。全部沿用冻结基线，仅阈值按需调整并记录。

报告边界：可以写"当前验收结构上的电荷重排与电子态调制"。 不得仅凭这些静态量推导 Li⁺ 扩散系数、阻抗、循环寿命或完整包覆层行为——那需要 MD 或更大尺度模拟。 另外，Bader 分析前必须先做价电子校验。
