COST-CONTROLLED ROUTE

重新制定后的低成本执行路线

当前目标只是获得一个可用于后续 DFT 性质计算的优化结构，不先承担完整主动学习训练和大规模 DFT 标签成本。

01直接预训练势优化DPA4 高参数 checkpoint 先跑通，不先做训练
02利用历史 48 帧先整理已有能量和结构
03少量 SCF 校准2–3 帧比较 1e-5 / 1e-6
04有需要再微调每轮 DFT 单点少于 10 个
05最终 DFT 验收受力与电子性质分开确认
执行优先级：先用 DPA4 系列参数量最高 checkpoint 直接优化当前结构；把已有 50 帧中的 48 帧整理成历史数据资产；只对 2–3 个代表帧做 SCF 阈值校准。若力的 MAE/RMSE 差异可接受，就直接推进结构验收，不启动从头训练。只有模型在界面环境中明显失效时，才进入“预训练模型微调 + 每轮少于 10 个 DFT 单点”的主动学习闭环。
两个判据要分开：不同 SCF 收敛限之间的力差异用可动原子力的 MAE/RMSE 判断；最终结构能否进入电子性质计算，仍用目标 DFT 下可动原子最大受力分量 ≤ 0.05 eV/Å 判断。磁性异质结难收敛时，优先尝试读取匹配的波函数/电荷作为初猜；1e-5 可作为校准候选，但必须用力差异验证。
模型选择：本方案采用 DPA4 系列参数量最高的 checkpoint。参数量最高不等于对 LRM/LPO 磁性界面一定最准确，仍必须核对元素覆盖、参考泛函、磁性处理和 DFT-D 定义，并做单帧能量/力验证；推理统一使用双精度。

LABEL-PRECISION CALIBRATION

先做标签精度标定，再谈训练

这一步回答一个独立问题：SCF 收敛限取多严，力的标签才算可靠。它不属于训练监控，而是一次性标定，成本约 2–3 h 机时（2–3 帧 × 3 个阈值）。

操作

  1. 从历史 48 帧中挑 2–3 个代表帧：建议初期高受力帧、中期帧、末期低受力帧各一。
  2. 每帧在 1e-4 / 1e-5 / 1e-6 三个 SCF 阈值下各做一次单点，其余参数完全不变（一次只改一个变量）。
  3. 比较可动原子的逐分量力，计算 MAE 与 RMSE——不要用最大偏差，单个原子的偶然离群会主导结论。
  4. 同时记录 SCF 迭代次数与机时，得到“阈值 → 力偏差 → 成本”三条曲线。
<SCF_THRESHOLD_CALIBRATION> --frames representative_*.stru --thresholds 1e-4 1e-5 1e-6 --movable-mask 00_input/movable_atoms.txt --metric mae,rmse --out 01_preflight/threshold_calibration.json

判据与结论口径

  • 若相邻阈值之间可动原子力的 MAE/RMSE 已在 1e-3 eV/Å 量级或更低，取较松的那个阈值作为生产口径。
  • 导师意见是 1e-5 通常已足够，但必须用实测力差异验证，不能直接采用。
  • 两个判据不要混：力差异的收敛口径用 MAE/RMSE；结构能否进入电子性质计算，用目标 DFT 下可动原子最大受力分量 ≤ 0.05 eV/Å。
  • 难收敛时的加速手段：读取同一几何邻域的波函数/电荷作为初猜、调 mixing、必要时用 uramping。

已知反例（本课题 leg1）：50 次 SCF 中有 2 次（第 10、11 步）撞满 scf_nmax = 600 仍不收敛，末次 DRHO ≈ 4×10⁻⁵，其中一步单步能量跳变 79.93 eV。这类病态步在 1e-5 阈值下同样不会收敛——放宽阈值救不了它，真正的杠杆是更好的起始几何与更强的收敛手段。

LEGACY DATA AUDIT

历史 48 帧：先审计，再当数据资产

已有的弛豫轨迹是零成本标签，但它是一条单一盆地的下降路径，不是构型空间采样。必须先过四道审计，才能进训练集或评测集。

四道审计

  1. 剔除未收敛步：按 leg1 审计排除第 10、11 步（DRHO ≈ 4×10⁻⁵、单步能量跳 79.93 eV）。这些帧的受力不可信，且其后约 30 步的受力震荡至少部分属数值污染。
  2. 磁态一致性：逐帧提取总磁矩与各 TM 位点局域磁矩，画沿步数曲线。DFT+U + nspin 2 下 SCF 可能落到不同自旋解；跳变帧必须单独成组或剔除，其能量不可与其他帧直接比较。
  3. 描述符去重：轨迹末段相邻帧能量差已降到 0.28–0.42 meV/atom，几何近乎重复。用 FPS 或信息熵类判据去重，预期独立有效构型只有 8–15 个。
  4. 可动/固定分开统计：固定原子带建模代价（本课题实测固定层最大受力 1.115 eV/Å），不参与收敛判据，但作为标签保留。

这批数据的三个用途与一个禁区

  • 首选 · 零样本评测集：用目标 checkpoint 对其推理，比较能量曲线与力的 MAE/RMSE。成本仅几分钟，直接回答“要不要微调”。
  • 次选 · 微调数据的种子：去重 + 磁态核查后的 8–15 帧作为第 0 轮微调集。
  • 再次 · 标定代表帧来源：见上一节。
  • 禁区 · 不能当独立验证集：一旦用于训练就不能再用它评估模型。验证集必须另建 20–50 帧，覆盖 bulk LRM / bulk LPO / 界面 / 缺陷-无序四类环境，全程不参与训练。

PROTOCOL & PRECISION

协议与精度约定：三条先钉死的口径

这三条不改变流程，但会决定后面所有数字能不能互相比较。

1 · DFT-D 色散要外挂，不要让模型去学

本课题 DFT 标签用 vdw_method = d3_bj，ABACUS 侧 vdw_cutoff_radius = 95 Bohr ≈ 50 Å。而 DPA4 是局域描述符模型（截断半径约 6 Å）——1/r⁶ 的长程项在物理上无法被局域模型表示，喂再多标签也学不出来。

  • 正确做法：在 ML 侧外挂 D3(BJ)，能量与力分别相加。
  • 必须匹配 ABACUS 口径：vdw_abc = 0（无三体项）、BJ 阻尼、s6/s8/a1/a2 取 default。
  • 同时按 DPA4 文章/模型卡确认预训练数据是否自带色散；若不带，外挂是唯一正确路径。

2 · 可动/固定不可混算

ABACUS 的收敛判据 Largest gradient in force 只统计可动原子。本课题实测：全部 288 原子最大分量 0.947 eV/Å，其中固定层 48 个原子占 0.947，可动 240 原子只有 0.400 eV/Å。若用全原子最大值当判据，会把 0.400 误读成 0.947，把“距判据 8 倍”误判成“19 倍”。

3 · 推理统一使用双精度

总能量是 ~2×10⁵ eV 的大数，而待分辨的信号在 meV/atom 量级。float32 的 machine epsilon 为 1.19e-7，在 2×10⁵ eV 上的最小可分辨步长约 0.024 eV（折合 0.083 meV/atom），与弛豫末段相邻帧 0.28–0.42 meV/atom 的差值是同一量级——float32 无法可靠分辨这类能量差。

  • 力与几何优化到 0.05 eV/Å：float32 可接受（噪声约 1e-3 eV/Å，低于判据约 50 倍）。
  • 候选帧能量比较、零样本/微调误差表、磁态能量排序：必须 float64。
  • checkpoint 权重本身的 dtype 决定上限：把推理切成 float64 不能恢复已丢失的精度。用 dp show 查模型信息并写入 manifest。
  • 文件往返也要查 dtype：.npy 存成 float32、.cif 只写 4–6 位小数、CSV/JSON 用 %.6g 写 −200885.724407（会变成 −200886，误差 0.7 eV）都会毁掉精度。

05B每轮微调：三种变体、采纳门与超参

两种机制是正交的

主动学习是采样策略（决定去算哪些 DFT），微调是更新策略（决定拿到标签后怎么改模型）。二者不互斥；标准做法是把微调放进每一轮闭环内部，而不是整个流程外做一次。

  1. 变体 A（推荐默认）：每轮从原始预训练 checkpoint 重新微调，训练集用累计标签。成本随轮数线性增长但仍然很小，无累积漂移，可复现、可回退。
  2. 变体 B：从上一轮 checkpoint 继续微调（warm start）。最省，但有两个累积风险：灾难性遗忘（逐轮向最新标签过拟合，早期化学被冲掉）与误差累积（某轮混进坏标签后无法回退）。若采用，必须同时启用 replay buffer 与采纳门。
  3. 变体 C（禁用）：每轮从随机权重从头训练。样本量差 2–3 个数量级——本课题可用标签仅数十帧，从头训练需 10⁴–10⁶ 构型——且会丢弃预训练先验。

采纳门与超参

  • replay buffer：每轮训练集固定保留历史标签的 30–50%，抑制遗忘。
  • 模型采纳门：只有独立验证集误差有改善才采纳新模型，否则回退上一轮；每轮 checkpoint 永久保留。
  • 停止条件：新增帧对验证集无改善，说明标签未提供新信息——转去改采样策略（换温度、应变、起点、缺陷环境），不要继续烧 DFT。
  • 按轮次递减：第 1 轮学习率较大、可解冻较多层；第 2–3 轮中等、部分冻结；后期学习率很小、只训拟合头。
  • 数据量口径：每轮新增 6–10 帧是采样节奏；导师经验值是累计到几百个结构的量级。两者不矛盾——引用“几百”时必须注明是累计目标，并分摊到多轮。
  • 委员会成本：经典 DP-GEN 用 4 个模型的分歧选帧，若每轮微调 4 个则成本 ×4；单模型 + 事件驱动规则成本 ×1 但依赖经验。折中方案是 2 个不同种子模型的力偏差作辅助信号。

通过与回退

通过后把结构复制到 06_properties/accepted/，冻结坐标并写验收报告。若残余力集中在少量界面原子，可补标签或做短程 DFT 几何细化。残余受力的位置决定下一步改什么：若受力集中在非晶 Li₃PO₄ 块而不是界面，继续加离子步只是在磨非晶应变，杠杆在界面配置（间距、配准）。
