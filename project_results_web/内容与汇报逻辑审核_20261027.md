## 主要判断

网页的主要数值有来源且相互一致，但原有图例、参数口径和电子钝化表述需要修正。已调整为：实验背景 → 三个科学问题 → 模型与方案 → 结构适用范围 → 结合能 → 差分电荷 → Mulliken → DOS/PDOS → 逐项回答问题 → 瓶颈与后续计算。

## 已修正的内容

1. **图例**：VESTA 图使用黄色积累、青色耗尽；平面平均与投影图使用金黄正、蓝色负。去掉错误的统一橙蓝图例。三维等值面为 ±0.003 e/Å³。
2. **投影方向**：二维图是沿 c 平均的 x–y 投影，单位仍为 e/Å³；x 为法向，y 为面内方向。不能据此描述完整 b–c 面的二维非均匀分布。
3. **参数口径**：方案的优化自洽为 1e−6 / 300 步；已有静态 INPUT 为 1e−7 / 400 步，三套分别 185 / 341 / 63 步。SCF 占据展宽 0.002 Ry 与 DOS 谱线展宽 0.05 eV 分开注明。
4. **结合能解释**：增补三个总能量、公式、参考态、面积和界面数；明确未作 BSSE 校正或系统采样/基组/磁态检验，不能以负号认定结构稳定。
5. **DOS 读图**：注明不同体系各用自身 EF 为零，尚未共同能量对齐；普通图按体系总原子数、相区图按各相区原子数归一化。TDOS 的负轴为自旋镜像；元素加和不能直接称为单一轨道。
6. **电子钝化**：从“初步支持电子钝化”收紧为“电子态调制有证据，钝化待检验”。见下表。
7. **结构前提**：在证据前明确尚未完成受力和配位验收。约 1.68 Å 的短 TM—O 接触是需复核的风险信号，单个最短距离不足以判定整体结构失稳。
8. **展示**：取消无数据定义的百分比装饰条；图片改为完整包含，避免坐标轴和图例被裁剪；结论区逐项回答用户原来的三个问题。

## 钝化结论为什么需要收紧

以下比较分别以各体系自身 EF 为零。点值单位 states/eV/cell，积分单位 states/cell。

| 指标 | 冻结 LRM B1 | 界面 A 中对应贡献 | 观察 |
|---|---:|---:|---|
| Mn-d D(EF) | 2.9772 | 2.0533 | 下降约 31.0% |
| LRM 相区 D(EF) | 26.9028 | 19.2087 | 下降约 28.6% |
| Mn-d [−0.5,0] eV 积分 | 1.4271 | 1.5216 | 略增 |
| LRM 相区 [−0.5,0] eV 积分 | 13.2800 | 15.8814 | 增加 |

因此 EF 点下降不能推广为整个近费米能区的态均被削弱。尚未定位哪些是与副反应有关的“有害表面态”，也缺少共同能量对齐及同一表层原子的对照。O-p 主导、LRM 相区占比高、峰重叠本身均不能证明钝化。

优先在验收结构上比较冻结参照与优化裸表面，明确两种参照各回答什么问题；控制磁态、采样和归一化，再做分层/原子投影。成键问题可补充 COHP/COOP、ELF；这些也不能单独替代针对副反应的验证。

## 仍需后续计算或确认

- **结构**：核查受力、停止原因、配位与厚度，完成优化；电子收敛不等于结构稳定。
- **原子归属**：上传方案为 LRM96/LPO96，已有结果为 97/95，一个 Li 的分组不同。已有结果内部对应，但不能混用另一分组的片段总能；后续统一版本和映射。
- **采样与基组**：验证面内 k 点、展宽、基组及磁性解。当前不能严格判定金属/半导体/绝缘体。
- **原子电荷**：P 的 Bader 分区异常尚未解决；Mulliken 不等于氧化态，也不意味着 Bader 已修复。
- **电势与输运**：未对齐电势不能给出可靠带阶、功函数或内建电场。静态电荷和 DOS 不能直接推出倍率、GITT 表观扩散系数、阻抗或循环性能。
- **实验尺度**：192 原子有限片段不能等同于完整 5 nm 非晶包覆层或所有界面构型。
