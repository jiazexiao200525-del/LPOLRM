01 / FOUNDATIONS

基础概念：原子为什么会移动？

这一层解决“结构、能量和力”之间的关系，是理解 ML 优化和 DFT 优化的共同基础。

势能面

给定元素、晶胞和所有原子坐标，每个构型都有一个能量。所有构型与能量的关系就是势能面，原子力来自能量对坐标的负梯度。

能量与原子力

能量告诉我们构型相对高低，原子力告诉优化器原子更倾向向哪里移动。能量和力必须来自同一套物理模型，才能用于一致的结构优化。

局部极小

优化通常从一个起点寻找附近的低谷。得到一个低受力结构，只说明在给定模型、晶胞和约束下接近局部极小，不自动等于全局最稳定界面。

03 / ACTIVE LEARNING

主动学习：模型怎样“指出没把握”？

主动学习不是模型凭空变聪明，而是用 DFT 对最有信息量的构型做标注，再用新标签更新模型。

采样

采样的是完整构型。从一条 ML 优化轨迹中选出初始、早期、中期、后期、配位变化或异常事件帧，而不是随机抽取几个原子。

不确定度

不确定度是筛选线索，不是真实误差。常见方法是多个训练有差异的模型预测同一结构，比较它们的力分歧；同一个 checkpoint 复制三份不能形成有效委员会。

DFT 标签

DFT 提供能量和逐原子力。固定几何单点只标注当前结构，不必先把每一帧都优化到低受力；但电子自洽必须可靠。

模型更新

选帧、DFT 标注、微调、重新探索四步连起来才构成主动学习闭环。只跑 ML 轨迹而不加入新标签，不是完整主动学习。

04 / DFT ACCEPTANCE

DFT 单点、SCF 与受力验收

DFT 在这里既是训练标签来源，也是最终决定 ML 结构能否进入电子性质计算的验收方法。

01 · DFT 单点固定原子求电子

得到当前几何下的能量、电子密度和力。

02 · SCF电子自洽迭代

电子密度与有效势反复更新直到收敛。

03 · DFT 力检查移动趋势

判断原子在目标 DFT 下是否仍有明显驱动力。

04 · 受力门槛可动原子 ≤ 0.05

项目标准为最大受力分量 ≤ 0.05 eV/Å。

05 · 几何检查配位与骨架

同时检查 PO₄、LRM 层状结构和异常短接触。

06 · 通过冻结几何

保留验收后的结构用于后续电子性质。

07 · 未通过补标签或细化

把可靠 DFT 力纳入下一轮，或做短程 DFT 优化。

三种收敛要分开：模型训练收敛 ≠ ML 几何优化收敛 ≠ DFT 电子自洽收敛。最终几何是否可用，还要看目标 DFT 下的残余力和局部结构。

05 / ELECTRONIC STRUCTURE

电子结构：结构通过后研究什么？

ML 势负责结构的能量和力；差分电荷、DOS/PDOS 和结合能仍由收敛的 DFT 电子计算提供。

差分电荷密度 Δρ

比较界面电子密度与相同晶胞、相同坐标下的冻结片段密度，观察界面接触引起的电子积累和耗尽。它描述重排，不直接给出形式氧化态。

DOS 与 PDOS

DOS 看能量处有多少电子态；PDOS 进一步分解到元素、原子、轨道或自旋。峰重叠是轨道相互作用线索，不单独证明化学键。

结合能

在明确参考态下比较界面和冻结片段的能量。负值支持当前参考下的能量降低，但不单独证明结构已弛豫稳定或是全局最低。

一句话边界：ML 负责快速走结构，主动学习负责决定哪里值得做 DFT，DFT 单点负责验收能量和受力，电子结构计算负责解释界面电子机制。
