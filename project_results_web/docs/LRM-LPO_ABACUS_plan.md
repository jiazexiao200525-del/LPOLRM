# LRM\-非晶Li3PO4\-ABACUS计算方案1

## 1\. 研究背景与计算目标

实验比较裸富锂锰基层状氧化物（LRM）与ALD\-Li₃PO₄包覆的LRM。根据测试需求，实验包覆层约5 nm，包覆样品表现出更好的倍率性能、更高的GITT表观Li⁺扩散系数及更低的阻抗。

本阶段计算重点回答三个问题：

1. LRM与非晶Li₃PO₄（LPO）能否形成稳定的局部界面结构？

2. 界面结合是否有利，接触区域发生了怎样的电荷重排？

3. 包覆后界面附近的电子态如何变化，是否存在支持电子钝化解释的证据？

本方案不直接计算Li⁺迁移势垒或扩散系数。结合能、电荷和DOS结果可以辅助解释界面作用，但不能单独证明离子迁移能垒降低，也不能直接换算实验扩散系数或阻抗。通过这些计算能不能说明测试需求的问题，能不能将机理解释清楚，达到什么样的结构能够说明要计算的需求

## 2\. 当前模型与统一计算基准

### 2\.1 模型定义

LPO采用此前由Packmol构建、经高温退火及0 K结构优化得到的非晶结构作为来源，不再按待定晶型处理。LRM采用已构建的（001）表面；当前界面模型如下。

|项目|当前模型设置|
|---|---|
|LRM部分|Li₂₉Mn₁₃Co₃Ni₃O₄₈，共96个原子|
|非晶LPO部分|Li₃₆P₁₂O₄₈，共96个原子|
|总组成|Li₆₅Mn₁₃Co₃Ni₃O₉₆P₁₂，共192个原子|
|真空方向|沿a轴|
|面内周期|b、c方向|
|几何优化|固定晶胞，所有原子放松|
|结构来源|在当前已选界面的最近优化结构上续算|

不因修订方案而重新平移、切割或增删原子。几何优化会改变原子相对位置，这是松弛过程的一部分；“采用原始非晶LPO作为来源”不表示优化后所有Li—O距离仍保持原值。

## 3\. 任务1：结构模型与优化

### 3\.1 目标

获得可用于能量和电子结构分析的LRM/非晶LPO界面，以及定义清晰的裸LRM参考。当前优先完成已有192原子界面的优化，不重新构建大量候选。

### 3\.2 计算难点

|难点|本任务的处理重点|
|---|---|
|电子收敛和结构收敛容易混淆|分别跟踪SCF残差和最大受力分量，不能仅看总能或退出状态|
|非晶局部环境多样，界面可能发生重构|逐个检查12个P的配位，并比较优化前后Li—O和过渡金属—O环境|
|薄LRM层与表面欠配位影响结果|记录层厚、表面变化及异常受力原子，明确有限模型的解释范围|
|磁态与几何变化相互影响|保留原子磁矩映射，遇到突变时同时核对电子与离子步骤|

目前问题：从早期的电子计算一直不收敛，转变为电子多数步骤能够收敛，但异质结原子仍在明显调整，最大受力反复，结构尚未达到平衡。

### 3\.3 计算流程

1. 核对当前结构的晶胞、192个原子、元素顺序、周期边界和真空位置。

2. 以最近一次有效优化结构作为BFGS起点，采用第2节完整参数。

3. 同时检查每个离子步的电子收敛、总能、最大受力分量和磁矩变化。

4. 优化结束后检查12个P的PO₄配位、P—O键长、Li—O及过渡金属—O环境、异常短距离和界面重构。配位统计必须考虑周期边界，并明确近邻判据。

5. 仅在最终SCF满足1e\-6、最大受力分量满足0\.05 eV/Å且结构检查通过后，将其标记为本方案标准下的收敛结构。

6. 需要裸表面电子结构参考时，另建由对应LRM部分得到的裸表面，并记录是否独立松弛。独立松弛裸表面与后文的冻结片段用途不同。

完整PO₄是结构检查的一项，不足以证明全部局部环境合理。尤其应检查Li—O近邻变化及薄LRM层的重构，避免只凭“P均为四配位”接受整个模型。

### 3\.4 续算与计算资源记录

当前BFGS续算采用前次输出的原生结构文件作为起点，并保留对应原子磁矩。此方式为从已有几何结构继续优化，不等同于恢复完整电子检查点或继承原优化器历史。

当前任务时限为100 h，使用32 CPU/64 GiB资源、16 MPI进程×1 OpenMP线程。资源设置与物理参数分开归档；时限不作为收敛判据。

## 4\. 任务2：界面结合能与黏附功

### 4\.1 计算对象及参考态

对通过验收的界面进行三组固定几何的静态计算：完整界面、删除LPO后留下的LRM片段、删除LRM后留下的LPO片段。两个片段均保留界面中的晶胞和原子坐标，不单独松弛。

保持泛函、U映射、赝势、轨道、色散修正、k点和电子精度一致。片段组成与总界面之间应满足原子数守恒，电子数及体系电荷需核对。

### 4\.2 定义与符号

冻结几何结合能定义为：

$E_{\mathrm{bind}}=E_{\mathrm{interface}}-E_{\mathrm{LRM,frozen}}-E_{\mathrm{LPO,frozen}}.$

在上述参考态下，负值表示结合降低能量。按面积归一化的黏附功为：

$W_{\mathrm{ad}}=\frac{E_{\mathrm{LRM,frozen}}+E_{\mathrm{LPO,frozen}}-E_{\mathrm{interface}}}{n_{\mathrm{int}}A},\qquad A=|\mathbf b\times\mathbf c|.$

其中，A为单个界面的面内面积，n\_int为晶胞内实际接触界面数。对于真空分隔、仅有一个LRM/LPO接触面的模型取1；必须检查具体周期结构，不能无条件除以2。报告eV、eV/Å²或J/m²时注明单位。

该定义反映冻结构型下的结合，不自动包含从独立体相或已松弛表面变形成该界面的全部能量代价。只有另行计算可比参考态，才能单独报告应变或形变能；不能将其列为已完成结果。

### 4\.3 参数与验收

静态计算沿用第2节电子参数，将`calculation`替换为`scf`，去掉几何优化专用行`relax_method`、`relax_nmax`和`force_thr_ev`。不得在INPUT中叠加重复参数。其余输出按任务需要配置。

基准仍为`scf_thr=1e-6`、`scf_nmax=300`、`mixing_beta=0.2`、`mixing_beta_mag=0.4`及Gaussian展宽0\.002 Ry，不再沿用旧方案中相互冲突的阈值、混合系数和网格。

三个体系都必须电子收敛。对较小结合能差，应追加电子阈值、k点或基组敏感性检查后再解释排序；采用不同轨道中心的片段比较还需关注基组叠加误差。当前基准不是误差为零的保证。

**输出：**三个总能、片段定义、界面面积及数目、结合能、黏附功、磁态与精度检查记录。

### 4\.4 计算难点

|难点|本任务的处理重点|
|---|---|
|参考态不一致会改变结合能含义|采用同一界面几何提取冻结片段，不混入独立松弛表面的能量|
|大总能相减得到较小差值|核对三组SCF收敛及精度一致性，必要时进行敏感性检验|
|删除组分后元素与磁态映射变化|逐项核对ntype、U、赝势、轨道、电子数及初始磁矩|
|面积、界面数与基组误差影响比较|核实实际接触界面数，统一归一化方式并记录基组误差检查|

### 4\.5 计算流程

1. 从任务1选取通过验收的界面，记录结构版本及原子归属。

2. 保持晶胞与坐标，分别删除LPO或LRM，生成两组冻结片段。

3. 核对片段组成之和等于完整界面，修正各自元素列表及U映射。

4. 按第4\.3节配置三组静态SCF，保留一致的物理参数、k点及色散处理。

5. 验证三组SCF均收敛，提取总能和磁态；未收敛的能量不进入差值计算。

6. 根据第4\.2节公式计算结合能，核对面积与界面数后计算黏附功。

7. 记录精度敏感性和参考态限制，给出结合趋势及其可信范围。

## 5\. 任务4：差分电荷密度与Bader电荷

### 5\.1 目标与计算方法

采用第4节的完整界面和两组冻结片段，分析界面形成前后的电荷重排。差分电子密度定义为：

$\Delta\rho(\mathbf r)=\rho_{\mathrm{interface}}(\mathbf r)-\rho_{\mathrm{LRM,frozen}}(\mathbf r)-\rho_{\mathrm{LPO,frozen}}(\mathbf r).$

若采用正值表示电子数密度的约定，正的差分表示电子积累，负值表示电子耗尽；图注明确这一约定。自旋极化体系分析总电子密度时使用两自旋通道之和，磁化密度另行标注。

### 5\.2 计算难点

|难点|本任务的处理重点|
|---|---|
|三套密度无法直接逐点相减|严格核对晶胞、原点、网格、单位及对应坐标|
|自旋及密度类型容易混用|区分总电子密度与磁化密度，记录赝势密度及价电子定义|
|Bader电荷依赖网格和原子映射|检查积分与网格敏感性，保留片段到界面的原子编号对应表|
|电荷变化容易被过度解读|明确符号和参考态，不将Bader净电荷直接解释为形式氧化态|

### 5\.3 计算流程

1. 继承第4节静态计算基准，配置所用ABACUS版本支持的电荷密度输出。

2. 核对三套密度的晶胞、原点、网格尺寸、单位、坐标及积分电子数完全对应。

3. 计算差分密度，生成界面三维等值面和沿a方向的平面平均曲线。

4. 进行Bader分区，保留原子编号与界面原子的一一映射。

5. 对比界面与冻结参考中的原子电荷，重点分析接触区域O、P、Li及Mn/Co/Ni。

6. 检查网格敏感性，将电荷重排与界面成键、结合能共同讨论。

### 5\.4 参数及解释边界

电子参数保持`scf_thr=1e-6`、Gaussian展宽0\.002 Ry及当前混合设置；不再在本节单独改成0\.01 Ry或mixing\_beta=0\.08。电荷输出及网格转换属于后处理任务的新增配置，执行前按LTS v3\.10\.1验证，不能据当前优化输入声称已经输出了可用的密度文件。

Bader表须区分“分区电子数”和“按赝势价电子数定义的净电荷”，说明符号约定及密度类型。Bader净电荷不是形式氧化态，不以一个绝对电荷值直接判定金属价态。

**输出：**差分电荷密度文件、三维图、a方向平面平均图、逐原子Bader表和界面电荷变化汇总。

## 6\. 任务5：DOS/PDOS与界面电子态

### 6\.1 目标与模型

比较界面与裸LRM参考的电子态，分析非晶LPO接触后费米能级附近态及局部成键环境的变化。必要时加入非晶LPO参考，不以某个晶态LPO替代当前非晶来源而不加说明。

参考模型应标明是界面中的冻结片段，还是独立松弛后的裸表面。两种参考分别反映固定几何下的接触作用及包含结构松弛的综合变化，不混在同一结论中。

### 6\.2 计算难点

|难点|本任务的处理重点|
|---|---|
|不同采样和展宽会改变峰形|记录实际k点、能量步长、谱线展宽与能带范围，比较敏感性|
|参考模型和能量零点不一致|区分冻结片段与松弛裸表面，注明各自费米能级或统一电势参考|
|元素总投影掩盖局部界面态|按接触区域和元素/轨道分组，保留原子编号与归一化方式|
|DOS变化不等于直接证明电子钝化|与结构及电荷结果交叉解释，明确薄层、非晶构型和U设置的限制|

### 6\.3 计算流程

1. 在收敛结构上完成静态SCF，继承第4节的统一电子设置。

2. 根据目标能区核对能带数量，按安装版本配置DOS/PDOS输出。

3. 以1×3×2为当前结构的采样基准，测试面内更密k点对谱形的影响，真空a方向保持1点。

4. 统一DOS分析能区、能量步长和谱线展宽，记录最终采用值。

5. 提取Mn/Co/Ni\-d、O/P\-p、Li\-s投影，并按LRM、LPO及接触区域分组；薄层中没有足够体相环境时，不强行标注“体相层”。

6. 明确能量参考，再结合结构、电荷和结合能讨论界面态。

### 6\.4 参数及解释边界

当前电子占据展宽为`smearing_sigma=0.002 Ry`，与DOS绘图所用谱线展宽不同。后者、能量步长、能区、额外能带及输出开关属于待配置的分析设置，不是当前优化任务已有参数。旧方案中的DOS示例数值不再作为已执行值保留。

各体系将自身费米能级置零，只能表示相对各自费米能级的谱线，不能直接视为绝对能带对齐。若讨论能带偏移，应另外验证可比电势或真空参考。

## 7\. 计算顺序、风险与验收

执行顺序：当前界面BFGS优化及结构检查 → 冻结片段静态计算与结合能 → 差分电荷/Bader → DOS/PDOS → 综合讨论。电荷和DOS不再依赖迁移计算结果。

|问题|检查与处理|
|---|---|
|SCF残差振荡|先检查短距离、电子数、磁矩和U占据，再在同一固定结构上有针对性对照混合及预条件；不预设混合比例一定要增大或减小|
|SCF收敛但力不收敛|检查最大受力原子、离子步长和局部重构，区分几何震荡与电子噪声；不单凭总能下降判定完成|
|到达200个离子步或100 h|检查最终有效结构和收敛标志；到限是停止条件，不是成功标准|
|PO₄保持完整但局部结构异常|同时检查Li—O、过渡金属—O、表面欠配位和周期边界短接触|
|片段能量不可比|核对冻结坐标、晶胞、k点、电子设置、U映射、磁态及色散修正|
|差分密度出现伪影|核对三套网格、原点、单位、电子数和自旋密度定义|
|DOS出现尖峰或结果随网格变化明显|检查采样、谱线展宽、能带范围和投影定义，再解释物理意义|
|续算读取失败|核对结构、轨道、版本和电子文件兼容性；区分几何续算与完整检查点恢复|

结构验收必须同时满足电子收敛、力收敛和几何合理性。报告保留未收敛SCF步及异常信息；不能把程序正常结束直接写成“完全收敛”。关键定量结论所需的额外精度检验单独记录，不悄悄替换本方案的当前参数基准。
